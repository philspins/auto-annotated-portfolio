## Project Overview

Developed a suite of specialized diagnostic harnesses that enable direct communication with vehicle Controller Area Network (CAN) systems. These tools are critical for field maintenance, troubleshooting, and firmware updates on military vehicles.

## Technical Implementation

The harnesses combine custom hardware interfaces with sophisticated software protocols to safely interact with vehicle electronics. The system can read diagnostic trouble codes, monitor real-time vehicle parameters, and perform firmware updates without risking damage to mission-critical vehicle systems.

## Key Capabilities

- **Real-time Data Collection**: Monitor CAN bus traffic and extract diagnostic information
- **Firmware Flashing**: Safely update vehicle controller firmware in the field
- **Multi-Protocol Support**: Compatible with various CAN communication standards
- **Fault Diagnosis**: Identify and troubleshoot electronic system issues

## Applications

These harnesses are used by field service technicians for:
- Routine vehicle diagnostics
- Pre-deployment system checks
- Firmware updates and patches
- Troubleshooting electrical system faults

## Technologies Used

- CAN Bus Protocol
- C# for software interfaces
- Custom hardware design
- J1939 Protocol
